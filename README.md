# Hospital-Emergency-Room-Analysis
An interactive Power BI dashboard analyzing emergency room data to explore patient admissions, waiting times, satisfaction levels, referral patterns, and operational trends.

## Project Overview
This project focuses on analyzing hospital emergency room data to understand patient flow and operational performance. The dashboard provides an overview of patient visits, demographics, waiting times, satisfaction levels, and department referrals to help identify important patterns in emergency room activity.

## Dataset Overview

- **Total Patient Records:** 9,216
- **Data Category:** Hospital Emergency Room Data
- **Analysis Focus:** Patient visits, waiting times, satisfaction, admissions and referrals.

## Tools & Technologies

- **Power BI:** Dashboard development and data visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Creating calculated measures and KPIs.
- **Data Modeling:** Organizing data for interactive analysis.

## Dashboard Pages

The dashboard consists of four interactive pages:

1. **Monthly View:** Examines monthly patient activity and emergency room trends.
2. **Consolidated View:** Provides an overall summary of key emergency room performance indicators.
3. **Patient Details:** Explores patient-level information and demographic patterns.
4. **Key Takeaways:** Highlights important observations and insights from the analysis.

## Key Performance Indicators

The dashboard focuses on monitoring:

- Total patient visits.
- Average patient waiting time.
- Patient satisfaction scores.
- Patient admission patterns.
- Department referral distribution.
- Patient demographics.

## Key Areas of Analysis

- Patient visits and admission trends.
- Waiting time patterns and patient experience.
- Patient distribution across demographic groups.
- Department-wise referral patterns.
- Patient activity by day and hour.
